# Installed AeRift app icons

Approved source: `assets/branding/aerift-logo.png`, Git blob `3cca436a55c86a9c14f447a96805b45ea7d46342`, SHA-256 `2aa3948cead24d7afeb23d9b417943ef869bcaf776f2e5182eeb97161fe7476f`. The generator checks this checksum before use. It applies full-frame integer area resampling, not a crop, redrawing, or style substitution. iOS strips an entirely opaque alpha channel; the Android adaptive foreground adds outer transparency for launcher masking.

- **Windows:** the checked-in ICO provides 16, 24, 32, 48, and 256 px entries. The existing Tauri bundle icon feeds the app executable and default window icon (which the tray copies). NSIS selects the same ICO explicitly. The isolated installed shell smoke checks extracted associations for both installer and installed executable against the source icon. This does not observe Explorer's cache or the actual tray on a personal desktop.
- **iOS:** project preparation replaces the generated AppIcon catalog with a universal 1024 RGB image. The same preparation step is used by simulator and archive tooling. Simulator smoke checks the compiled primary icon name and file references. A signed archive, TestFlight upload, and a physical Home Screen are separate gates.
- **Android:** project preparation generates legacy density PNGs, a bitmap adaptive foreground with a dark background, and manifest references for both regular and round launchers. Significant bright details are inside the 66 dp mask-safe circle. The APK verifier checks that compiled manifest references select the branded resources. Signature verification, AAB and tester installation remain separate existing gates.

Regenerate Windows inputs with `python3 scripts/branding/app-icons.py windows apps/aerift/src-tauri/icons`; run `python3 scripts/branding/test-app-icons.py` for checksum, generation, ICO/RGB structure, asset pixels and Android safe-zone tests. The mobile generators use only Python standard library as part of platform preparation. No startup cinema, art replacement, signing setting, distribution workflow or personal-device action is part of this change.
