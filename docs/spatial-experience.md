# AeRift spatial experience

Transferring a file should feel like moving an object through space. Keep the source, destination, and object recognizable as the user selects, holds, sends, receives, and recovers a file.

- **Spatial Workspace** anchors the current device and gives discovered peers stable positions. Use the compact arrangement for narrow screens or crowded workspaces. The dock keeps selection, sending, and gesture controls within reach. Activity shows receipts and recovery actions. Control Center holds device management and preferences.
- **Materials** follow four roles. The canvas holds ordinary text and a living optical environment. Integrated rows and empty states have minimal elevation. Interactive objects and navigation use the theme’s signature material. Dialogs and popovers float above the workspace. GLASS keeps the approved [optical calibration](../packages/ui/glass-design.md) and adds subtle softness without washing out the ribbons beneath the glass.
- **Appearance** is independent of theme. GLASS uses shared ribbon geometry with luminous blue and violet against deep black in Dark, and pearl white, ice blue, and lavender in Light. Tune optics and illumination per appearance. System follows the OS while AeRift is running. Appearance changes preserve file selection, navigation, camera intent, and transfers.
- **Object Experience** reuses one presentation for selected and transferred files. Recognition drives anticipation and hold. Release hands off to the existing transfer action. When recognition is lost or canceled, return to the selected file if the local selection is still valid. Native pickers and the Windows drop surface currently select one file at a time.
- **The Rift** follows authoritative receipts and uses one transport identity on both devices. A paired receiver may advertise readiness for a short lease. Every offer still requires explicit acceptance, and progress uses reported bytes. Completion appears only after native verification and storage. Motion runs locally and never controls network timing.
- **Access and lifecycle** keep pointer, touch, keyboard, and conventional transfer actions available. Users opt in to gestures through Control Center. The camera listens automatically for an eligible file and recipient or incoming offer in the foreground, and its indicator reflects the real camera state. Guidance appears on detection. Respect reduced motion, reduced transparency, contrast, and platform lifecycle. Preserve readable state and controls when motion is suppressed.
