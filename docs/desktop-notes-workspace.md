# Desktop Notes workspace

Use a low-noise navigation sidebar and a large editing pane, borrowing the layout model from Apple Notes and the existing AeRift Glass and Motion system for all surfaces. Show category names, note titles and search data as content. Tools and chrome use icons with accessible names, native tooltips, keyboard actions and visible focus, not word-button strips. The same Notes list, editable categories, Recents and icon editor are used on iPhone and Android. Mobile opens the list by default and switches to a dedicated full-width editor with a Back to Notes icon. Mobile keeps native attachment preview, entry selection and Rift sharing. Respect reduced motion.

The desktop sidebar offers All Notes, Recents (up to 20), named categories, and scoped title/body search. Note saves and edits update local recency. Older installed notes never stored reliable creation/edit times, so unstamped notes keep the prior storage order instead of inventing timestamps. Categories group existing note IDs; deleting a category does not delete its notes. Selecting a note loads its content on the right. Notes save explicitly (icon or Ctrl+S); changing notes or returning to Workspace with a draft prompts to save or discard.

Do not migrate the existing v1 IndexedDB store or change its portable object schema. Category and modification metadata are bounded, local and separate from the note bodies. A metadata write failure must not overwrite earlier state or claim the category changed. The installed v1 writer continues to use the original note data.

Hosted browser acceptance exercises creating a category, saving formatted notes, recency, scoped search, persistence on reload, large editor space and icon-only tools, plus the mobile and existing collection journeys. It is not installed Windows verification.
