# AeRift Ambient A1–A3

Ambient captures a deliberately chosen digital object in its existing application. It must not activate a different app, scrape a screen, simulate input, read the clipboard automatically, or infer a recipient. Capture is separate from offer, receipt, and verified completion.

## Applicable build
This initial Windows implementation provides opt-in, global Explorer capture via **Ctrl + Alt + Shift + A** while another application is active, including while the app's primary window is hidden in the notification area. This trigger is a deliberate native hotkey, not simulated input and not a substitute for the remaining system-wide camera work. The capture can be reviewed in Control Center without initiating a transfer. After a separate manual choice of an online paired Nearby device, one frozen regular file can use the existing v1 offer/accept flow; other captures remain intact and are not silently down-converted. It expires after two minutes and is replaced only by a new explicit pickup. Enable both notification-area operation and the separate capture shortcut in Windows Control Center. Pause or resume from the notification area. The existing launch-at-login setting still applies. Unknown, secure, and locked input desktops are held suspended; manual pause/disable/exclusion reconfiguration discards the current capture and invalidates work in flight. No camera is activated by the new capture path. The existing in-app camera indicator and local camera model processing stay unchanged.

### Contracts and privacy boundaries

- **A1:** Native process owns capture lifecycle and initiates the existing networking session independently of a renderer subscription when Ambient is enabled. Setup never starts the camera. A single in-flight worker owns native capture. A generation invalidates stale work on policy changes while the active input desktop is checked before capture, during long fingerprinting, and before exposing the frozen result. The foreground identity is sampled synchronously at pickup; if it changes before the extraction finishes, no replacement capture is made. Polling is limited to the opt-in runtime. The lifecycle contract distinguishes suspended, reduced, and normal processing; the capture host samples Windows Battery Saver. An independent background camera engine does not consume this policy yet. Camera use outside the focused main WebView, releasing an OS camera on lock/excluded-app changes in that engine, and true window-independent recognition are **not shipped** by this change. Closing to tray hides the window; OS destruction of that WebView is not the same operation.
- **A2:** `RiftObjectKind` covers files, directories, image/video, webpage/URL, plain/rich text, documents, spreadsheet ranges, code, clipboard, notes, locations, media references and collections. This defines representations, not new automatic adapters or wire support. `ContextAdapter` defines local snapshot extraction; `CaptureContext` resolves explicit selection, explicit targets, active document/media, active page, then nothing. Unavailable explicit content never falls through, and sensitive contexts abort without resolution. Metadata includes an optional native source identifier, a preview descriptor, bounded relative names, byte length and SHA-256 where applicable. File reads use a reusable 1 MiB buffer without temporary copies. Frozen entries retain a private locator, a full digest and per-block digests. The v1 sender authenticates a complete block before emitting any of its bytes, and the unmodified v1 receiver verifies the full digest before publishing. The current transfer protocol supports one regular raw file; the object-manifest wire capability remains prospective. Individual file transfers from the existing picker are unchanged. Directory entries are fixed at capture time, including empty directories, with added members not implicitly included.
- **A3:** The adapter anchors the foreground/focused Shell view, checks trusted native Explorer identity, then queries the selected item array through Shell COM/STA. Desktop selection is constrained to the real shell process. Arrays are bounded and rechecked before snapshot completion. Active filesystem folder is an independent receiving hint; folder contents are never assumed selected. The adapter does not call SetForegroundWindow, send application input, alter selections, or use clipboard/OCR. Virtual items, unsupported windows, elevated apps, links/reparse points, malformed and unreadable paths, network paths, and cloud/offline/recall placeholders fail closed. Focused text controls are refused. Selected text through UI Automation and active-document adapters are not implemented: provider capability, non-password text proof and explicit capture boundaries must be qualified first.

### Future seams
A4 can consume a frozen capture through the process-owned runtime after purpose-bound explicit destination authority becomes available. A5 can subscribe to scoped status events without receiving file paths or camera frames. A6 supplies an explicit trusted browser adapter into the same resolver, not title/address-bar scraping. App exclusions are locally configured executable basenames. Nearby, My Devices, Remote and Friends keep their independent grants; resolving or freezing an object never changes pairing, availability claims, recipient consent, or authorization.

### Qualification
Run the workspace Rust suite; the host's Linux cross-check is limited where an MSVC C/assembly toolchain is unavailable. Hosted Windows compilation/installer checks do not prove real camera/Explorer interactions. Before promoting, qualify on an authorized physical Windows machine: dual Explorer tabs, desktop and multiple nested selections, switching foreground mid-request, same-count selection changes, virtual/cloud/elevated contexts, manual pause, secure desktop and session lock/unlock, refusal without altering focus/selection, and original local manual and gesture paths. No real files or camera frames are uploaded as CI artifacts.

The staged [native camera lifecycle](ambient-native-camera.md) describes the next A1 seam. It is separate from the shipped focused camera path.
